При сохранении договора реквизиты контрагента сохраняются отдельно. Существующая карточка с тем же ИНН не перезаписывается автоматически. Для изменения используйте кнопку «Обновить контрагента».

Параметры договора

ФИО руководителя — именительный падеж

Вводите ФИО и должность в именительном падеже. В преамбуле используется родительный, в подписях — фамилия и инициалы. Для нестандартных фамилий проверьте склонение.

Дополнительное соглашение

Формирование счетов

Счета составляются по основному договору и выбранным дополнительным соглашениям. Нумерация: номер договора.0, номер договора.1 и далее.

Формирование документов

Выберите, по каким документам составить акт. Можно сформировать отдельный акт по договору, по каждому соглашению или один общий акт по выбранным услугам.

Налогообложение

Без НДС. Формулировка фиксирована для договора, приложения и актов. Применять при наличии законного основания не начислять НДС.

Перед подписанием проверьте налоговый статус Исполнителя, лицензии и реквизиты Сторон. Услуги сдаются единым комплексом.

Проверка реквизитов карточки
